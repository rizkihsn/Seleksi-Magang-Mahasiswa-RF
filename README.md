# Simulasi Random Forest - Prediksi Penerimaan Seleksi Magang

Tugas Machine Learning - Kelompok 2B
Rizki Hasan Fauzi (NIM 301240071, Kelas 5B, Teknik Informatika, UNIBBA)

Web simulasi algoritma Random Forest (bootstrap, gain ratio/C4.5, mayoritas vote) tanpa library, hanya HTML + JavaScript.

## Cara menjalankan
Buka `index.html` di browser, atau deploy ke Vercel (Add New > Project > impor repository ini, Framework Preset: Other, tanpa build command).

## Struktur
- `index.html`, `style.css`: tampilan
- `core.js`: algoritma Random Forest
- `data.js`: dataset studi kasus (14 data, 4 atribut)
- `app.js`: logika antarmuka
- `vercel.json`: konfigurasi deploy Vercel
